# 01 · Your first pull request

This one is about the Git and GitHub steps, not the code.

## Task

1. Make a branch called `ex-01-first-pr`.
2. Open [`CLASS.md`](CLASS.md) and add a row about yourself.
3. Commit with a message like `Add myself to CLASS.md`.
4. Push the branch and open a pull request.

## Then try this

When the review comes back with a comment, make the change, commit and push
again. Watch the same PR update without you opening a new one.

## Think about

- What does `git status` say after you edit the file but before `git add`?
- On GitHub, open the **Files changed** tab of your PR. What do the green and red lines mean?
- Why do you think we don't just edit `main` directly?
