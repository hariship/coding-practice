# 02 · Predict the output

Good programmers can read code and know what it will do **before** running it.
This exercise trains that.

## Task

For each file `p1_…py` to `p8_…py`:

1. Read it. **Don't run it yet.**
2. In [`answers.md`](answers.md), write down exactly what you think it will print.
3. Now run it: `python exercises\02_predict\p1_boxes.py`
4. Write what it actually printed.
5. If you were wrong, write **why** in one or two lines. This is the important part.

Getting some wrong is expected. The "why" lines are what we'll talk about in review.

## New thing in p8

`while` is a loop that keeps going **as long as** its condition is true.
It checks the condition before every round.
